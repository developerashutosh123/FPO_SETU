# 03-bank-portal: working notes

Credit officer console of the fictional Subarnarekha Krishi Bank (Next.js 16 App Router, TypeScript strict, Tailwind 4). Read `../shared/CONTRACT.md`, `../shared/PORTAL_COMMON.md` and `PROMPT.md` first. The contract wins over anything here.

## Commands
- `pnpm mock` (mock gateway, :4010), `pnpm dev` (:3003, runs `scripts/sync-contract.mjs` first). `.env.local` copies `.env.example` (`NEXT_PUBLIC_DATA_SOURCE=mock`, `NEXT_PUBLIC_DEMO_MODE=true`).
- `pnpm check` = typecheck + vitest. `pnpm test:e2e` = Playwright against the mock (see `docs/TESTING.md` for the WSL library workaround).
- `pnpm build` fails unless `NEXT_PUBLIC_DATA_SOURCE=live`. Local check: `NEXT_PUBLIC_DATA_SOURCE=live NEXT_PUBLIC_API_URL=http://localhost:4010 pnpm build`.

## Folders
- `src/lib/api.ts`: the only module that calls the gateway (failover, `X-Ledger-Mode`, ngrok header, JWT). `errors.ts` is the message map. `portals.ts` holds the other portals' URLs and `DEMO_MODE`.
- `src/components/`: `AppShell` (status pill, banners, `useWritesEnabled`), `ProofDrawer`, `LienDialog` (mark lien + duplicate demo), `finance.tsx` (receipt card, error notices).
- `src/app/collateral`, `src/app/loans`: the pages. `/collateral/[enwr]` and `/loans/[loanId]` are inbound deep links.
- `src/contract/`, `src/styles/tokens.css`: GENERATED by `scripts/sync-contract.mjs`. Never edit. Committed so Vercel can build without `../shared`.

## Loan state machine (from `00-core-ledger/chaincode/pledge-lien`)
SANCTIONED (lien marked) -> disburse -> DISBURSED -> repay until total >= principal -> REPAID -> release -> RELEASED. The UI enables each button only in its own state.

## Never do
- Invent tx IDs, block numbers, endorsers, prices or figures; show a designed empty state. Valuation numbers come from the API, not from client arithmetic.
- Show a farmer name, phone or crop diary (contract 9.4), or link to the buyer portal or the farmer statement.
- Edit `../shared/` or another portal's folder; requests go in `CONTRACT_REQUESTS.md`.
- Ship `NEXT_PUBLIC_DATA_SOURCE=mock`, use emoji icons (Lucide only) or em dashes in UI copy.
