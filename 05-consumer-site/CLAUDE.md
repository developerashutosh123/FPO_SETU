# 05-consumer-site: working notes

Public provenance page that the pack QR links to (Next.js 16 App Router, TypeScript strict, Tailwind 4). Read `../shared/CONTRACT.md`, `../shared/PORTAL_COMMON.md` and `PROMPT.md` first. The contract wins over anything here. Built thin: only `/` and `/00/[sscc]`, English and Bengali. `PROMPT.md` lists the rest (scan camera, `/01/...`, `/report`, `/how-it-works`, `/credits`, `/about`, Hindi, map, photos), not built yet.

## Commands
- `pnpm mock` (mock gateway :4010), `pnpm dev` (:3005; runs `scripts/sync-contract.mjs`). `.env.local` copies `.env.example`.
- `pnpm check` = typecheck + vitest. `pnpm test:e2e` = Playwright against the mock (see HUMAN_STEPS.md for the WSL Chromium library workaround).
- `pnpm build` fails unless `NEXT_PUBLIC_DATA_SOURCE=live`. Local test: `NEXT_PUBLIC_DATA_SOURCE=live NEXT_PUBLIC_API_URL=http://localhost:4010 pnpm build`.

## Folders
- `src/lib/api.ts`: the only module that calls the gateway. Server side only: `/health` probe (8 s, retry once) then failover to the read API, ngrok header on ngrok hosts, provenance fetch cached 60 s.
- `src/lib/lang.ts`, `src/i18n/{en,bn}.json`: language comes from `?lang=bn` (default English). Both files must have identical keys and placeholders (unit test). `bn.json` keeps `_review: true`.
- `src/components/Provenance.tsx`: the lot page body. `Shell.tsx`: header, language links, contract footer.
- `src/app/lookup/route.ts`: manual lot-number form, redirects to `/00/{sscc}` (works without JS).
- `src/contract/`, `src/styles/tokens.css`: GENERATED by `scripts/sync-contract.mjs`. Never edit.

## Never do
- Show a farmer name or phone, the crop diary, prices or loan terms. The e2e test greps the server-rendered HTML for every seeded name, phone, id and token.
- Write "GI" or "geographical indication" (contract section 4.1), em dashes in UI copy, emoji icons (Lucide only).
- Invent tx IDs, endorsers or statistics. The page shows channel members from contract section 7, not endorsers.
- Edit `../shared/` or another portal's folder. Requests go in `CONTRACT_REQUESTS.md`.
- Ship `NEXT_PUBLIC_DATA_SOURCE=mock`.
