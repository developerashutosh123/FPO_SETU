# 04-buyer-portal: working notes

Procurement portal of the fictional Gangetic Fresh Foods Pvt Ltd (Next.js 16 App Router, TypeScript strict, Tailwind 4). Read `../shared/CONTRACT.md`, `../shared/PORTAL_COMMON.md` and `PROMPT.md` first. The contract wins over anything here.

## Built so far (P0-P3, against the mock)
Catalogue `/`, lot spec sheet `/lots/[sscc]`, orders `/orders`, `/orders/new`, `/orders/[id]` (two-step sealed-price agreement), `/receive` (QR scan, accept custody, accept quality, demo-only FPO attempt).
Not built (out of the agreed scope): `/supplier`, evidence-pack PDF, `/credits`, `/about`, real photography, Bengali/i18n (buyer is English only), P4-P6.

## Commands
- `pnpm mock` (mock gateway, :4010), `pnpm dev` (:3004, runs `scripts/sync-contract.mjs` first). `.env.local` copies `.env.example`.
- `pnpm check` = typecheck + vitest. `pnpm test:e2e` = Playwright against the mock (see `docs/TESTING.md`).
- `pnpm build` fails unless `NEXT_PUBLIC_DATA_SOURCE=live`. Local check: `NEXT_PUBLIC_DATA_SOURCE=live NEXT_PUBLIC_API_URL=http://localhost:4010 pnpm build`.

## Folders
- `src/lib/api.ts`: the only module that calls the gateway (failover, `X-Ledger-Mode`, ngrok header, JWT). `stream.ts` is the SSE hook (fetch-based, because EventSource cannot send the ngrok header). `errors.ts` is the message map. `portals.ts` holds other portals' URLs and `DEMO_MODE`.
- `src/components/`: `AppShell` (status pill, banners, demo bar, toasts, `useWritesEnabled`), `ProofDrawer`, `trade.tsx` (receipt card, write error, chips), `lot/` (map, chart, Re-verify).
- `src/contract/`, `src/styles/tokens.css`: GENERATED by `scripts/sync-contract.mjs`. Never edit. Committed so Vercel can build without `../shared`.

## Price agreement (F6)
The buyer never sends a salt; the gateway derives it, so both sides' hashes agree. The page shows the hash the gateway returns (the client cannot compute it: the salt is a server secret). Order status and the agreed price are always re-read from the ledger; the local `submitted` state only drives the waiting view.

## Never do
- Invent tx IDs, block numbers, endorsers, prices or figures; show a designed empty state.
- Show the crop diary, a farmer name or phone, a lien, loan or e-NWR, or link to the bank portal or farmer data (contract 9.4).
- Edit `../shared/` or another portal's folder; requests go in `CONTRACT_REQUESTS.md`.
- Ship `NEXT_PUBLIC_DATA_SOURCE=mock`, use emoji icons (Lucide only) or em dashes in UI copy.
