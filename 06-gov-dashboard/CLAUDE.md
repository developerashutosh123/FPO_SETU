# 06-gov-dashboard: working notes

Governance dashboard and public Ledger Explorer (Next.js 16 App Router, TypeScript strict, Tailwind 4). Read `../shared/CONTRACT.md`, `../shared/PORTAL_COMMON.md` and `PROMPT.md` first. The contract wins over anything here.

## Commands
- `pnpm mock` (mock gateway, :4010), `pnpm dev` (:3006, runs `scripts/sync-contract.mjs` first). `.env.local` copies `.env.example` (`NEXT_PUBLIC_DATA_SOURCE=mock`).
- `pnpm check` = typecheck + vitest. `pnpm test:e2e` = Playwright against the mock (needs `pnpm exec playwright install chromium`).
- `pnpm build` fails unless `NEXT_PUBLIC_DATA_SOURCE=live` (guard in `next.config.ts`). To test a build locally: `NEXT_PUBLIC_DATA_SOURCE=live NEXT_PUBLIC_API_URL=http://localhost:4010 pnpm build`.
- Index-only failover e2e: see `docs/TESTING.md`.

## Folders
- `src/lib/api.ts`: the only module that calls the gateway (failover, `X-Ledger-Mode`, ngrok header, JWT, error map in `errors.ts`). Isomorphic: the tx and block pages are server-rendered.
- `src/lib/useApi.ts`, `useLedgerStream.ts`: client data hook and the one SSE hook (fetch-based so the ngrok header can be sent; polls every 30 s in index-only mode).
- `src/lib/explain.ts`: plain-English tx summary and timeline labels, derived from `fn` and key names only.
- `src/contract/`, `src/styles/tokens.css`: GENERATED by `scripts/sync-contract.mjs`. Never edit. Committed so Vercel can build without `../shared`.
- `src/app/`: routes. `/ledger`, `/ledger/tx/*`, `/ledger/block/*` are public; `/`, `/network`, `/lots/*` use `<RequireAuth>` (observer or board).
- `tests/`: Playwright. `src/**/*.test.ts`: vitest.

## Never do
- Invent tx IDs, block numbers, endorsers, prices or KPIs; show a designed empty state instead.
- Render any price (₹ or INR) for an order, any farmer name or phone, loan terms, or crop-diary detail. The observer is not on trade-channel.
- Edit `../shared/` or another portal's folder. Contract change requests go in `CONTRACT_REQUESTS.md`.
- Ship `NEXT_PUBLIC_DATA_SOURCE=mock`, add real logos or the State Emblem, use emoji icons (Lucide only) or em dashes in UI copy.
- Compare hashes in the browser and present it as a ledger fact (the real gateway's `previousHash` is the previous block header hash, which `BlockDetail` does not carry).
