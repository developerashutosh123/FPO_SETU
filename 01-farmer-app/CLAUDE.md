# 01-farmer-app (Expo, web build, Bengali first)

Farmer app of FPO-SETU. Answers one question: "What happened to my lot, and what was I paid?" Read `../shared/CONTRACT.md`, `../shared/PORTAL_COMMON.md`, `../shared/contract.ts` and `PROMPT.md` first. If this file and the contract disagree, the contract wins.

## Scope of this build
Web only. In: language picker, phone + demo OTP login, device key, home, lot detail, payment statement with read-aloud, confirm lot (F2) with device signing, profile, live toasts. Out for now: VLE mode, consent screen, crop diary, prices, erase-my-data, offline outbox, EAS Update, APK.

## Commands
```
pnpm install            # hoisted node_modules (see pnpm-workspace.yaml)
node ../shared/mock/server.mjs        # mock gateway :4010 (demo password Setu@2026, OTP 123456, phone 9000000001)
pnpm dev                # Expo web on :3001 against the mock (EXPO_PUBLIC_DATA_SOURCE=mock)
pnpm check              # tsc + vitest
pnpm build:mock && node scripts/serve-dist.mjs   # production bundle against the mock, served on :3001
pnpm e2e                # Playwright against that bundle (needs pnpm build:mock first)
pnpm build              # REFUSES unless EXPO_PUBLIC_DATA_SOURCE=live and both API URLs are set (scripts/check-build-env.mjs)
SHOTS=1 pnpm e2e screenshots   # refresh docs/screenshots
```

## Folders
- `app/` expo-router routes. `lot/[sscc]`, `statement/[sscc]` are the inbound links; `confirm/[sscc]` is F2.
- `src/lib/api.ts` the only module that talks to the gateway (probe, failover, ngrok header). `stream.ts` SSE with fetch.
- `src/lib/signing.ts` pure signing helpers; `deviceKey.ts` the non-extractable WebCrypto key in IndexedDB.
- `src/lib/numberWords.ts`, `statementScript.ts` what "read aloud" says.
- `src/i18n/{bn,hi,en}.json` same keys in all three; `bn.json` is `"_review": true` until a native speaker has read it.
- `src/contract/contract.ts` and `src/styles/tokens.css` are GENERATED by `scripts/sync-contract.mjs` from `../shared`. Never edit them; commit the copies (Vercel has no `../shared`).
- `CONTRACT_REQUESTS.md` change requests to the contract.

## Never do
- Edit `../shared/` or another portal's folder. Write a request in `CONTRACT_REQUESTS.md` and tell the human.
- Invent ledger data: tx IDs, block numbers, endorsers, prices, KPIs. Show what the API returns, or a designed empty state that says why.
- Re-serialise `payloadToSign`. It is signed exactly as received.
- Put a name, phone number or plot coordinates on screen where the API did not send them for this role, or on the ledger.
- Use text below 16 sp, touch targets below 48, emoji as icons (Lucide only), em dashes in copy, AI images, real institution logos.
- Ship a build with `EXPO_PUBLIC_DATA_SOURCE=mock`.
- Use `EventSource` for `/events/stream` (free ngrok serves it the interstitial). Use the fetch reader in `src/lib/stream.ts`.
- Commit files outside this folder. Conventional commits; `git pull --rebase` first.
